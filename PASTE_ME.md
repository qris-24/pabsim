## Deck identity (design objectives, not claims the build meets them)
- Self-sustaining Golgari inevitability engine: accumulate resources, contain the table (Savra edicts + lifegain), survive dismantling, then convert into a sudden lethal sequence.
- Not turbo combo, not a grindy drain deck, not an infinite-loop deck. Loops are for value, not win lines.
- Payoffs stay in hand until the table can be drained. Minimal per-turn leak. The drain should read to the table as a lifegain value deck.
- Life floor for spending life: 15. Savra edict frequency is a policy variable. No turn deadlines.

## Standing rules
- Savra is the only irreplaceable card. Nothing is added or removed without explicit user approval.
- Every proposal needs mechanical justification, pros/cons, and a full 100-card pasteable list (`1x Name (set) [Category]`; commander `1x Name (set) *F* [Commander{top}]`).

- Otherwise kernel bugs are fixed as found. All kernel engineering is authorized until a stop point.
- Usage: one scoped task per session; named file paths; tests with -q, tails only; no decklists or results printed to the terminal; no re-reads of files just edited; stop after 2 failed attempts; /clear between unrelated tasks.
